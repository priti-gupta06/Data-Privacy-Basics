# Data-Privacy-Basics
identify sensitive information and recommend basic protection method.

## Project Overview
This project was completed as part of the Cyber Security Internship Track at Veda Technology. The objective is to identify different types of information, classify data according to its sensitivity, and recommend basic security measures to protect it.

## Objectives
- Understand data classification and privacy principles.
- Identify public, internal, confidential, and sensitive information.
- Recommend suitable access controls and protection measures.
- Understand data minimization and responsible data handling.

## Tools Used
- Google Sheets

## Project Contents
The workbook includes:
- Data classification table
- Risk levels for different types of information
- Access permissions and data owners
- Recommended security measures
- Data privacy guide and principles

## Data Classification Categories
1. Public : Information approved for public sharing.
2. Internal : Information intended for authorized employees or teams.
3. Confidential : Information that requires restricted access.
4. Sensitive : Highly protected information requiring strict safeguards.

## Key Security Measures
- Apply least-privilege access.
- Use strong passwords and multi-factor authentication.
- Encrypt sensitive information where appropriate.
- Mask personal information when possible.
- Follow data retention and secure deletion practices.
- Collect only the information required for a legitimate purpose.

## Learning Outcomes
Through this project, I learned how data classification supports information security, reduces the risk of unauthorized disclosure, and helps organizations select suitable protection measures.
